### 1.spring boot 打包并上传

在已经继承了 spring-boot-starter-parent 下，pom.xml:

```xml

<build>
    <plugins>
        <plugin>
            <groupId>org.springframework.boot</groupId>
            <artifactId>spring-boot-maven-plugin</artifactId>
        </plugin>
    </plugins>
</build>
```

执行命令：

```java
mvn clean package
scp 你的包名.jar admin@服务器IP:/home/admin/apps/项目名字
```

### 2.运行

2.1 前台运行

```java
java -jar /opt/app/app.jar
```

2.2  后台运行

```java
nohup java -jar /opt/app/app.jar > app.log 2>&1 &
```

2.3 检测

```
pgrep -af "app.jar"
kill PID
```

2.4 查日志

```
less app.log
```
