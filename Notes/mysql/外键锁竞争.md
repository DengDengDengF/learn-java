| 时间   | 事务 A                                                       | 事务 B                                                       | 状态说明                                             |
| :----- | :----------------------------------------------------------- | :----------------------------------------------------------- | :--------------------------------------------------- |
| **T1** | `INSERT order_items (order_id=1)` 👉 外键检查，拿父表 **`id=1` 的 S 锁** |                                                              | A 拿到 1 的 S 锁                                     |
| **T2** |                                                              | `INSERT order_items (order_id=2)` 👉 外键检查，拿父表 **`id=2` 的 S 锁** | B 拿到 2 的 S 锁（**注：这里B先执行了图里的步骤2**） |
| **T3** | `UPDATE orders WHERE id=2` 👉 想要 **`id=2` 的 X 锁**         |                                                              | A 被 B 在 T2 拿的 S 锁**卡住，等待**                 |
| **T4** |                                                              | `UPDATE orders WHERE id=1` 👉 想要 **`id=1` 的 X 锁**         | B 被 A 在 T1 拿的 S 锁**卡住，等待**                 |

由于事务A `T3 `等事务B `T2` ,导致 `T1` 无法释放锁。

由于事务B `T4` 等事务A `T1` 导致 `T2` 无法释放锁。

互相持有锁，但又都无法释放。
